# UTM Source - Marketing Parameter

> Track and analyze UTM parameters and marketing referrals for your Shopware 6 orders.

## Overview

The UTM Source - Marketing Parameter plugin enables complete tracking of your customer origins. Learn exactly which marketing channels generate your orders – whether through Google Ads, social media campaigns, newsletters, or other sources.

The plugin automatically captures all URL parameters (such as utm_source, utm_medium, utm_campaign), the referrer (origin page), and customer device information. This data is directly linked to the order and available in the order overview.

With the cookie-less tracking option, you can meet GDPR requirements while still capturing valuable marketing data.

## Key Features

- **UTM Parameter Capture**: Automatic capture of all URL parameters such as utm_source, utm_medium, utm_campaign, and any custom parameters
- **Referrer Tracking**: Storage of the visitor's origin page (e.g., Google, Facebook, newsletter links)
- **Device Detection**: Capture of device type (Desktop/Mobile/Tablet), browser, and operating system
- **Cookie-less Tracking**: Optionally work without cookies – ideal for GDPR-compliant shops
- **Order Attribution**: All captured data is automatically linked to the order
- **Admin Overview**: Direct display of all marketing data in the order detail view
- **Parameter Management**: Management and configuration of recognized marketing parameters
- **Automatic Cleanup**: Scheduled task for automatic deletion of old session data

## Requirements

- Shopware Version: 6.5.0 or higher (up to 6.7.x)
- PHP Version: 8.1 or higher

## Quick Start

1. Install the plugin via Plugin Manager or Composer
2. Activate the plugin in **Extensions → My Extensions**
3. Optional: Configure cookie-less capture in **Extensions → My Extensions → UTM Source - Marketing Parameter → Configure**
4. Capture begins automatically – marketing data appears in order details
