# Category Quick Filter

> Interactive multi-level category dropdown for Shopware 6 Shopping Experiences. Guides customers through deep category structures – perfect for vehicle selectors and printer supplies.

## Overview

The **Category Quick Filter** adds an interactive, multi-level dropdown menu to your Shopware 6 Shopping Experiences. Customers navigate step by step through your category hierarchy – no endless scrolling or searching required. Once the deepest level is reached, the widget automatically redirects to the matching category page or directly to the product.

The plugin is especially suited for shops with deep, structured product catalogs: automotive spare parts, printer cartridges, industrial accessories, or any product range that benefits from guiding customers through multiple selection steps. As a Shopping Experiences element, the widget can be placed flexibly on any page in your shop.

Multiple instances can be placed on the same page with different root categories – ideal for pages that present several product lines side by side.

## Key Features

- **Multi-level dropdown**: Up to 4 category levels configurable; each level dynamically loads the subcategories of the selected parent.
- **Automatic redirect**: When the deepest level is reached, the customer is automatically redirected to the category page – no additional click needed.
- **Direct product redirect**: Optional: if a category contains only one available product, the widget redirects directly to the product detail page.
- **Freely selectable root category**: You define the starting point of the dropdown – which category level appears as the first selection step.
- **Multiple instances**: Several widgets with different root categories can be placed on the same page without interfering with each other.
- **Pin top categories**: Important categories can be pinned to the top of the selection list so customers always see them immediately.
- **Shopping Experiences integration**: The widget is provided as a CMS block and element in Shopware Shopping Experiences, fully configurable via the visual editor.

## Requirements

- Shopware Version: 6.6.0 or higher (up to 6.7.x)
- PHP Version: 8.2 or higher

## Quick Start

1. Install the plugin via the Plugin Manager or Composer.
2. Activate the plugin under **Extensions → My Extensions**.
3. Open a Shopping Experience under **Content → Shopping Experiences** and add the **Category Selector** block from the **Commerce** category.
4. Click the element to configure it: select a root category, set the depth, and save the Shopping Experience.
