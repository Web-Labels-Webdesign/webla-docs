# Changelog

All notable changes to PayTR Integration for end-users.

---

## Version 1.0.0 - 2026-04-22

### ✨ New Features

- **PayTR payment method**: Customers pay by credit or debit card on PayTR's secure payment page.
- **Installments**: Installments can be disabled or limited to a maximum number.
- **Automatic payment status**: Orders are automatically set to **Paid** or **Failed** after payment.
- **Credential test**: **Test API Credentials** button in the plugin configuration.
- **Callback URL display**: The callback URL required in the PayTR Merchant Panel is shown in the configuration, ready to copy.
- **Test mode**: Test the payment flow without real payments.
- **Per sales channel configuration**: Separate PayTR credentials and settings per sales channel.
