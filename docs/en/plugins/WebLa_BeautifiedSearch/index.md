# Search as Overlay

> Enhances Shopware search with a modern overlay interface. Displays products, categories, blog articles and manufacturers in user-friendly tabbed results.

## Overview

The "Search as Overlay" plugin (WebLa Beautified Search) significantly improves the default search functionality of your Shopware 6 shop. Instead of a simple product list, your customers see a modern, clear interface with tabs for different result types.

This search is particularly useful for shops with extensive product ranges, many categories, or an integrated blog. Customers find what they're looking for faster because all relevant content is visible at a glance.

Additionally, the plugin offers intelligent product number search that can search directly by EAN, article number, or manufacturer number - ideal for B2B shops or customers who know exactly which product they need.

## Key Features

- **Tabbed Search Overlay**: Clear presentation of search results in tabs (Products, Categories, Blog, Manufacturers)
- **Category Search**: Shows matching categories for the search term, optionally with category images
- **Blog Integration**: Searches blog articles from NetzP Blog or H1 Web Blog
- **Manufacturer Search**: Shows matching manufacturers (when using Shopware Commercial Advanced Search)
- **Product Number Search**: Direct search by EAN, article number, or manufacturer number
- **Flexible Display**: Adjustable overlay width, column count, and product box layout
- **Multi-Version Support**: Supports Shopware 6.5, 6.6, and 6.7 with a unified codebase

## Requirements

- Shopware Version: 6.5.0 or higher (up to 6.7.x)
- PHP Version: 8.1 or higher

### Optional Integrations

- **NetzP Blog**: For blog search with the NetzP Blog plugin
- **H1 Web Blog**: For blog search with the H1 Web Blog plugin
- **Shopware Commercial Advanced Search**: For extended manufacturer search

## Quick Start

1. Install the plugin via Plugin Manager or Composer
2. Activate the plugin in **Extensions → My Extensions**
3. Configure basic settings in **Extensions → My Extensions → Search as Overlay → Configure**
4. Enable the desired search features (category search, blog search)
5. Clear the cache under **Settings → System → Caches & Indexes**
