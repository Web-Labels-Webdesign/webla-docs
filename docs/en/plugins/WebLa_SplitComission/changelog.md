# Changelog

All notable changes to SplitCommission — Division of Line Items into Parts.

---

## [5.0.0] – 2026-03-10

### ✨ New Features

- **Shopware 6.6 support**: The plugin now supports both Shopware 6.6 and 6.7 — a single plugin version works across both Shopware releases.

### 🔧 Improvements

- **Simplified maintenance**: A unified codebase for both Shopware versions — no separate branches needed.
- **Modernized release process**: New versions are delivered more reliably and faster via the Shopware Store.

### Compatibility

| Plugin Version | Shopware Version | PHP Version |
| -------------- | ---------------- | ----------- |
| 5.x            | 6.6.0 – 6.7.x   | 8.2+        |
| 4.x (legacy)   | 6.7.0 – 6.7.x   | 8.2+        |

---

## [4.0.0] – 2025-07-28

### ✨ New Features

- **Initial stable release** for Shopware 6.7.
- Commission note input field on the product detail page.
- Line item split functionality in the cart and off-canvas cart.
- Inline editing of commission notes in the cart.
- Optional global order comment field on the checkout confirmation page.
- Global comment displayed on the order success page.
- Commission notes shown in the Shopware admin order line items view.
- Tiered/bulk pricing preserved across split positions.
- Activatable globally for all products or individually per product (via custom field).

---

## Upgrade Notes

### Upgrading from 4.x to 5.0.0

The upgrade is seamless:
- No configuration changes required.
- All existing settings are preserved.
- Install the new version via the Plugin Manager or Shopware Store and clear the cache.

| 5.x            | 6.6.0 – 6.7.x   | 8.2+        |
