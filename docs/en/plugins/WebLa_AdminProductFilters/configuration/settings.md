# Configuration settings

> This plugin has no configurable settings.
> It works immediately after installation and activation.

You will therefore not find a *Configure* button for this plugin under **Extensions → My extensions**. This is intentional, not a fault.

## What you can control instead

The actual control does not happen in the plugin, but in two familiar places in Shopware:

| What you want to control                        | Where you set it                                                                       |
| ----------------------------------------------- | -------------------------------------------------------------------------------------- |
| Which custom fields are offered as a column      | **Settings → System → Custom fields** – the field set must be assigned to the *Products* entity |
| Which columns are actually displayed             | Column settings of the product list under **Catalogues → Products** (per user)          |
| How a column is labelled                         | The label of the field set and the custom field under **Settings → System → Custom fields** |
| How wide a column is                             | Drag the column border in the product list                                              |

For details, see the [usage guide](../usage/usage.md).
