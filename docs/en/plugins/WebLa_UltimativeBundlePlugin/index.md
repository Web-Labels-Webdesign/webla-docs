# Ultimate Bundle Plugin

> Create product bundles with automatic discounts, flexible group configurations and mobile-optimized display.

## Overview

The Ultimate Bundle Plugin enables you to create attractive product bundles in your Shopware shop. Customers can see pre-configured bundle offers on product detail pages and add all bundle products to the cart with a single click - including automatic discount calculation.

The plugin is ideal for cross-selling strategies, promotional bundles or complete package offers. Through the flexible group structure, you can combine different product categories and let your customers choose between multiple options per group. Optional groups and individual quantity selection per group provide maximum flexibility.

## Key Features

- **Create product bundles**: Combine any products into attractive bundle offers with automatic discounts
- **Flexible product groups**: Organize bundle products into groups with individual product sources (manual selection, product streams or categories)
- **Optional groups**: Allow customers to deselect individual groups of a bundle
- **Quantity selection per group**: Customers can set the quantity per bundle group individually (with configurable maximum)
- **Automatic bundle creation**: Bundles are optionally assembled automatically when matching products are in the cart
- **Flexible discount configuration**: Percentage discounts with various calculation modes and display options
- **Mobile-optimized display**: Separate, mobile-optimized view of the bundle selection
- **Product availability check**: Unavailable products can be automatically hidden
- **Bundle index**: Fast display through pre-calculated index for bundle-product assignments

## Requirements

- Shopware Version: 6.6.0 or higher (up to 6.8.0)
- PHP Version: 8.2 or higher

## Quick Start

1. Install the plugin via Plugin Manager or Composer
2. Activate the plugin in **Extensions → My Extensions**
3. Configure basic settings in **Extensions → My Extensions → Ultimate Bundle Plugin → Configure**
4. Create your first bundle in **Catalogues → Products → Bundles → Create bundle**
5. Assign products or product groups to the bundle and set the discount
