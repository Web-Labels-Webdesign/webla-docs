# Kundenspezifische Rabatte

> Vergeben Sie individuelle Rabatte pro Kunde auf Kategorien, Produktgruppen oder die gesamte Kundengruppe.

## Übersicht

**Kundenspezifische Rabatte** ermöglicht es Ihnen, individuelle Rabatte für Ihre Kunden zu vergeben - sei es auf bestimmte Kategorien, Dynamische Produktgruppen oder als globaler Rabatt für ganze Kundengruppen. Das Plugin ist ideal für B2B-Shops, Stammkundenpreise und individuelle Preisgestaltung.

Mit dem flexiblen Prioritätssystem können Sie genau steuern, welcher Rabatt angewendet wird, wenn mehrere Rabatte für ein Produkt in Frage kommen. Die Verwaltung erfolgt direkt im Kundenprofil oder in den Kundengruppen-Einstellungen im Shopware Admin.

## Hauptfunktionen

- **Produktrabatte**: Setzen Sie Rabatte direkt auf einzelne Produkte über Custom Fields
- **Individuelle Kundenrabatte**: Vergeben Sie Rabatte pro Kunde auf bestimmte Kategorien oder Dynamische Produktgruppen
- **Globale Kundenrabatte**: Geben Sie einzelnen Kunden einen globalen Rabatt für alle Produkte
- **Kundengruppen-Rabatte**: Vergeben Sie Rabatte für ganze Kundengruppen auf Kategorien oder Produktgruppen
- **Globale Gruppenrabatte**: Definieren Sie einen pauschalen Rabatt für alle Produkte einer Kundengruppe
- **Flexible Prioritätssteuerung**: Bestimmen Sie, welcher Rabatt bei Überschneidungen angewendet wird
- **Anpassbare Darstellung**: Wählen Sie zwischen separater Rabattposition oder reduziertem Preis

## Voraussetzungen

- Shopware Version: 6.5.0 bis 6.7.x
- PHP Version: 8.1 oder höher

## Schnellstart

1. Installieren Sie das Plugin über den Plugin Manager oder Composer
2. Aktivieren Sie das Plugin unter **Erweiterungen → Meine Erweiterungen**
3. Konfigurieren Sie die Grundeinstellungen unter **Erweiterungen → Meine Erweiterungen → Kundenspezifische Rabatte → Konfigurieren**
4. Öffnen Sie ein Kundenprofil und fügen Sie Rabatte im Bereich "Kundenrabatte" hinzu
