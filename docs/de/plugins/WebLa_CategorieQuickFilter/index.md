# Kategorie Schnellauswahl

> Interaktives mehrstufiges Kategorie-Dropdown für Shopware 6 Erlebniswelten. Führt Kunden schnell durch tiefe Kategoriestrukturen – ideal für Fahrzeugauswahl und Druckerzubehör.

## Übersicht

Die **Kategorie Schnellauswahl** ergänzt Ihre Shopware 6 Erlebniswelten um ein interaktives, mehrstufiges Dropdown-Menü. Kunden wählen Schritt für Schritt durch Ihre Kategoriehierarchie – ohne langes Scrollen oder mühsames Suchen. Sobald die tiefste Ebene erreicht ist, leitet das Widget automatisch zur passenden Kategorie oder direkt zum Produkt weiter.

Das Plugin ist besonders geeignet für Shops mit tiefen, strukturierten Produktkatalogen: Kfz-Ersatzteile, Druckerpatronen, Industriezubehör oder jedes andere Sortiment, das Kunden über mehrere Auswahlstufen führen soll. Durch die nahtlose Integration als Erlebniswelt-Element lässt sich das Widget flexibel auf jeder Shopseite einsetzen.

Mehrere Instanzen können auf derselben Seite mit unterschiedlichen Wurzelkategorien platziert werden – ideal für Seiten, die mehrere Produktlinien gleichzeitig präsentieren.

## Hauptfunktionen

- **Mehrstufiges Dropdown**: Bis zu 4 Kategorieebenen konfigurierbar; jede Ebene lädt dynamisch die Unterkategorien der gewählten übergeordneten Kategorie.
- **Automatische Weiterleitung**: Wenn die tiefste Ebene erreicht ist, wird der Kunde automatisch zur Kategorieseite weitergeleitet – kein zusätzlicher Klick nötig.
- **Direktweiterleitung zum Produkt**: Optional: Enthält eine Kategorie nur ein einziges verfügbares Produkt, leitet das Widget direkt zur Produktseite weiter.
- **Freie Wurzelkategorie**: Der Startpunkt des Dropdowns ist frei wählbar – Sie bestimmen, welche Kategorieebene als erste Auswahlstufe angezeigt wird.
- **Mehrfach einsetzbar**: Mehrere Widgets mit verschiedenen Wurzelkategorien können auf derselben Seite platziert werden, ohne sich gegenseitig zu beeinflussen.
- **Top-Kategorien fixieren**: Wichtige Kategorien können dauerhaft oben in der Auswahlliste fixiert werden, damit sie für Kunden immer sofort sichtbar sind.
- **Erlebniswelt-Integration**: Das Widget wird als CMS-Block und -Element in den Shopware Shopping Experiences bereitgestellt und ist damit vollständig über den visuellen Editor konfigurierbar.

## Voraussetzungen

- Shopware Version: 6.6.0 oder höher (bis 6.7.x)
- PHP Version: 8.2 oder höher

## Schnellstart

1. Installieren Sie das Plugin über den Plugin Manager oder Composer.
2. Aktivieren Sie das Plugin unter **Erweiterungen → Meine Erweiterungen**.
3. Öffnen Sie eine Erlebniswelt unter **Inhalte → Erlebniswelten** und fügen Sie den Block **Category Selector** aus der Kategorie **Commerce** ein.
4. Klicken Sie auf das Element, um es zu konfigurieren: Wählen Sie eine Wurzelkategorie, legen Sie die Tiefe fest und speichern Sie die Erlebniswelt.
