# Product Slider Advanced

> Erweiterter Slider für Produkte und Kategorien in Shopware 6

## Übersicht

Das Plugin **Product Slider Advanced** erweitert Ihren Shopware 6 Shop um einen flexibel konfigurierbaren Slider für Produkte und Kategorien. Mit diesem Plugin können Sie Ihre Produkte und Kategorien ansprechend in einem modernen Slider präsentieren und so die Aufmerksamkeit Ihrer Kunden gezielt auf bestimmte Bereiche Ihres Shops lenken.

Das Plugin integriert sich nahtlos in den Erlebniswelten-Editor von Shopware 6 und bietet Ihnen umfangreiche Gestaltungsmöglichkeiten. Sie können nicht nur Produkte, sondern auch Kategorien in einem Slider darstellen - ideal für die Startseite oder Landingpages.

Ein besonderes Highlight ist die integrierte Teaser-Funktion: Neben dem Slider können Sie einen ansprechenden Teaser-Bereich mit Bild, Überschrift, Text und Link einblenden, um zusätzliche Informationen oder Call-to-Actions zu platzieren.

## Hauptfunktionen

- **Flexible Produktauswahl**: Wählen Sie Produkte manuell aus, laden Sie sie aus einer Kategorie oder nutzen Sie dynamische Produktgruppen
- **Kategorie-Slider**: Präsentieren Sie mehrere Kategorien als Slider-Elemente mit Bild und Beschreibung
- **Integrierter Teaser**: Optionaler Teaser-Bereich neben dem Slider mit Bild, Text und Link
- **Responsive Design**: Optimierte Darstellung auf allen Endgeräten mit konfigurierbarem Mobile-Verhalten
- **Umfangreiche Styling-Optionen**: Passen Sie Farben, Abstände, Höhen und das Layout individuell an
- **Varianten-Steuerung**: Entscheiden Sie, ob Hauptprodukte, Varianten oder beides angezeigt werden sollen
- **Navigation & Autoplay**: Konfigurierbare Navigationspfeile, Punkte-Navigation und automatisches Scrollen

## Voraussetzungen

- Shopware Version: 6.5.0 oder höher (bis 6.7.x)
- PHP Version: Gemäß Shopware-Anforderungen

## Schnellstart

1. Installieren Sie das Plugin über den Plugin Manager oder Composer
2. Aktivieren Sie das Plugin unter **Erweiterungen → Meine Erweiterungen**
3. Öffnen Sie eine Erlebniswelt unter **Inhalte → Erlebniswelten**
4. Fügen Sie den Block **Produkt Slider Advanced** aus der Kategorie "Commerce" hinzu
5. Konfigurieren Sie den Inhaltstyp und wählen Sie Ihre Produkte oder Kategorien aus
