# Media Booster

> Automatische Bildoptimierung für Shopware 6. Komprimiert Bilder, konvertiert zu WebP/AVIF und optimiert SEO-Metadaten für schnellere Ladezeiten und bessere Rankings.

## Übersicht

Media Booster ist ein leistungsstarkes Plugin zur Bildoptimierung für Shopware 6, das Ihre Produktbilder und Medien automatisch verarbeitet. Das Plugin reduziert die Dateigröße Ihrer Bilder erheblich, während die visuelle Qualität erhalten bleibt - für schnellere Ladezeiten und ein besseres Einkaufserlebnis.

Die Optimierung erfolgt vollautomatisch im Hintergrund oder kann manuell über ein übersichtliches Dashboard gestartet werden. Dabei werden nicht nur die Bilder selbst optimiert, sondern auch deren SEO-relevante Metadaten wie Alt-Tags, Titel und Dateinamen können automatisch angepasst werden.

## Hauptfunktionen

- **Bildgrößenänderung**: Verkleinert übergroße Originalbilder automatisch auf konfigurierbare Maximalmaße, um Speicherplatz zu sparen
- **WebP-Konvertierung**: Konvertiert JPG, JPEG und PNG Bilder in das moderne WebP-Format für bis zu 30% kleinere Dateien
- **AVIF-Konvertierung**: Konvertiert Bilder in das hocheffiziente AVIF-Format für noch bessere Kompression
- **SEO-Optimierung Alt-Tags**: Füllt automatisch leere Alt-Tags mit Produktnamen oder konfigurierbaren Texten
- **SEO-Optimierung Titel**: Optimiert Bild-Titel für bessere Suchmaschinenindexierung
- **SEO-Optimierung Dateinamen**: Benennt Produktbilder SEO-freundlich nach Produktname, Artikelnummer oder Hersteller um
- **Hintergrundverarbeitung**: Verarbeitet Bilder schonend im Hintergrund ohne den Shop zu belasten
- **Dashboard**: Übersichtliches Admin-Panel mit Fortschrittsanzeige und Statistiken

## Voraussetzungen

- Shopware Version: 6.5.0 oder höher (bis 6.7.x)
- PHP Version: 8.1 oder höher
- PHP Imagick-Erweiterung (empfohlen für beste Ergebnisse) oder GD-Library
- WebP-Unterstützung in Imagick oder GD für WebP-Konvertierung
- AVIF-Unterstützung in Imagick oder GD für AVIF-Konvertierung

## Schnellstart

1. Installieren Sie das Plugin über den Plugin Manager oder Composer
2. Aktivieren Sie das Plugin unter **Erweiterungen → Meine Erweiterungen**
3. Konfigurieren Sie die Grundeinstellungen unter **Einstellungen → Erweiterungen → Media Booster**
4. Öffnen Sie das Dashboard unter **Einstellungen → Erweiterungen → Media Booster** und starten Sie die Verarbeitung mit "Alle starten"
