# UTM Source - Marketing Parameter

> Erfassen und analysieren Sie UTM-Parameter und Marketing-Verweise für Ihre Shopware 6 Bestellungen.

## Übersicht

Das Plugin UTM Source - Marketing Parameter ermöglicht Ihnen die vollständige Nachverfolgung der Herkunft Ihrer Kunden. Erfahren Sie genau, über welche Marketing-Kanäle Ihre Bestellungen generiert werden – sei es über Google Ads, Social Media Kampagnen, Newsletter oder andere Quellen.

Das Plugin erfasst automatisch alle URL-Parameter (wie utm_source, utm_medium, utm_campaign), den Referrer (Herkunftsseite) sowie Geräteinformationen des Kunden. Diese Daten werden direkt mit der Bestellung verknüpft und stehen Ihnen in der Bestellübersicht zur Verfügung.

Mit der Cookie-losen Tracking-Option erfüllen Sie die DSGVO-Anforderungen und können dennoch wertvolle Marketing-Daten erfassen.

## Hauptfunktionen

- **UTM-Parameter Erfassung**: Automatische Erfassung aller URL-Parameter wie utm_source, utm_medium, utm_campaign und beliebiger eigener Parameter
- **Referrer-Tracking**: Speicherung der Herkunftsseite des Besuchers (z.B. Google, Facebook, Newsletter-Links)
- **Geräteerkennung**: Erfassung von Gerätetyp (Desktop/Mobile/Tablet), Browser und Betriebssystem
- **Cookie-loses Tracking**: Optional ohne Cookies arbeiten – ideal für DSGVO-konforme Shops
- **Bestellzuordnung**: Alle erfassten Daten werden automatisch der Bestellung zugeordnet
- **Admin-Übersicht**: Direkte Anzeige aller Marketing-Daten in der Bestelldetailansicht
- **Parameter-Verwaltung**: Verwaltung und Konfiguration erkannter Marketing-Parameter
- **Automatische Bereinigung**: Geplante Aufgabe zur automatischen Löschung alter Session-Daten

## Voraussetzungen

- Shopware Version: 6.5.0 oder höher (bis 6.7.x)
- PHP Version: 8.1 oder höher

## Schnellstart

1. Installieren Sie das Plugin über den Plugin Manager oder Composer
2. Aktivieren Sie das Plugin unter **Erweiterungen → Meine Erweiterungen**
3. Optional: Konfigurieren Sie die Cookie-lose Erfassung unter **Erweiterungen → Meine Erweiterungen → UTM Source - Marketing Parameter → Konfigurieren**
4. Die Erfassung beginnt automatisch – Marketing-Daten erscheinen in den Bestelldetails
