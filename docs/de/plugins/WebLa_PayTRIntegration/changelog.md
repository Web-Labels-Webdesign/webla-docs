# Änderungsprotokoll

Alle wichtigen Änderungen an PayTR Integration für Endbenutzer.

---

## Version 1.0.0 - 2026-04-22

### ✨ Neue Funktionen

- **Zahlungsart PayTR**: Kunden bezahlen per Kredit- oder Debitkarte auf der sicheren PayTR-Zahlungsseite.
- **Ratenzahlung**: Ratenzahlung lässt sich deaktivieren oder auf eine Höchstzahl von Raten begrenzen.
- **Automatischer Zahlungsstatus**: Bestellungen werden nach der Zahlung automatisch auf **Bezahlt** oder **Fehlgeschlagen** gesetzt.
- **Zugangsdaten-Test**: Schaltfläche **API-Zugangsdaten testen** in der Plugin-Konfiguration.
- **Callback-URL-Anzeige**: Die im PayTR-Händlerpanel benötigte Callback-URL wird in der Konfiguration zum Kopieren angezeigt.
- **Testmodus**: Zahlungsablauf ohne echte Zahlungen testen.
- **Konfiguration pro Verkaufskanal**: Eigene PayTR-Zugangsdaten und Einstellungen je Verkaufskanal.
