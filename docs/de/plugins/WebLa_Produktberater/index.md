# Produkt Berater Plugin

> Interaktiver Produktberater für Shopware 6. Führen Sie Ihre Kunden durch gezielte Fragen zum passenden Produkt. Unterstützt verschiedene Fragetypen, Gewichtungen und Live-Updates.

## Übersicht

Der Produkt Berater ist ein intelligentes Empfehlungssystem, das Ihre Kunden in wenigen Schritten zum perfekten Produkt führt. Im Gegensatz zu klassischen Filtern arbeitet der Berater mit einer intelligenten Gewichtung: Wenn ein Kunde beispielsweise ein rotes Mountainbike mit bestimmten technischen Anforderungen sucht, Sie aber nur eines in Schwarz haben, empfiehlt der Berater trotzdem dieses Produkt – weil alle wichtigen Kriterien erfüllt sind.

Das Plugin ermöglicht es Ihnen, beliebig viele Produktberater zu erstellen, die Sie flexibel in Ihre Erlebniswelten einbinden können. Jeder Berater besteht aus einer Reihe von Fragen mit unterschiedlichen Antwortmöglichkeiten. Die Antworten werden gewichtet und führen zu einer intelligenten Produktempfehlung.

## Hauptfunktionen

- **Intelligente Gewichtung**: Jede Frage erhält eine individuelle Gewichtung. Technische Anforderungen können wichtiger sein als Farbwünsche.
- **Dynamische Produktgruppen**: Filtern Sie vorab, welche Produkte in den Berater einfließen (z.B. nur auf Lager, bestimmte Hersteller, Preisbereich).
- **Live-Aktualisierung**: Kunden sehen nach jeder Antwort sofort die passenden Produkte.
- **Herstellerpriorisierung**: Bevorzugen Sie bestimmte Marken in den Ergebnissen.
- **Bedingte Fragenlogik**: Überspringen Sie Fragen automatisch, wenn sie durch vorherige Antworten irrelevant werden.
- **Mehrsprachigkeit**: Übersetzen Sie Fragen und Antworten direkt im Berater – kein separater Berater pro Sprache nötig.
- **Varianten-Unterstützung**: Der Suchalgorithmus berücksichtigt auch Variantenoptionen.
- **Flexible Frageformate**: Buttons, Dropdowns, Bereichsauswahl oder Texteingabe.
- **CMS-Integration**: Einfache Einbindung in jede Erlebniswelt per Block.

## Voraussetzungen

- Shopware Version: 6.5.0 oder höher (bis 6.8.0)
- PHP Version: 8.1 oder höher

## Schnellstart

1. Installieren Sie das Plugin über `Erweiterungen → Meine Erweiterungen`
2. Aktivieren Sie das Plugin
3. Navigieren Sie zu `Kataloge → Produktberater`
4. Klicken Sie auf "Hinzufügen" um einen neuen Berater zu erstellen
5. Vergeben Sie einen Namen und fügen Sie Fragen hinzu
6. Binden Sie den Berater in eine Erlebniswelt ein unter `Inhalte → Erlebniswelten`
