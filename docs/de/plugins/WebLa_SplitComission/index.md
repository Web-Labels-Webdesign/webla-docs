# SplitCommission – Aufteilung der Einzelposten in Teile

> Ermöglicht Kunden, Warenkorb-Positionen mit individuellen Kommissionskommentaren zu versehen und in separate Teile aufzuteilen – bei vollem Erhalt der Staffelpreise.

## Übersicht

Das Plugin **SplitCommission** ist speziell für B2B-Händler entwickelt worden, die ihren Kunden ermöglichen möchten, Bestellpositionen mit individuellen Kommissions- oder Auftragskommentaren zu versehen. Ein Kunde kann zum Beispiel 10 Stück eines Artikels bestellen, davon aber 3 Stück mit dem Kommentar „Filiale Nord" und 7 Stück mit „Filiale Süd" kennzeichnen – als separate Positionen im Warenkorb.

Das besondere Highlight: Die Staffelpreise bleiben dabei vollständig erhalten. Das Plugin addiert alle Mengen des gleichen Artikels zusammen und wendet den korrekten Staffelrabatt auf alle Positionen an – unabhängig davon, wie viele Teilpositionen mit unterschiedlichen Kommentaren erstellt wurden.

Zusätzlich kann optional ein globales Kommentarfeld für die gesamte Bestellung aktiviert werden, das auf der Kassenseite erscheint und in der Bestellzusammenfassung sowie im Shopware-Admin sichtbar ist.

## Hauptfunktionen

- **Kommissionskommentar auf der Produktdetailseite**: Kunden können direkt beim Hinzufügen eines Artikels einen Kommentar eingeben. Der Artikel wird so als eigene, kommentierte Position in den Warenkorb gelegt.
- **Aufteilung im Warenkorb**: Bestehende Warenkorb-Positionen können nachträglich mit einem Kommissionskommentar versehen und in separate Positionen aufgeteilt werden.
- **Inline-Bearbeitung der Kommentare**: Bereits gesetzte Kommissionskommentare lassen sich direkt im Warenkorb bearbeiten – ohne Seitenreload.
- **Off-Canvas-Warenkorb**: Alle Kommentarfunktionen stehen auch im seitlichen Warenkorb (Off-Canvas) zur Verfügung.
- **Globaler Bestellkommentar**: Optional kann ein einziges Kommentarfeld für die gesamte Bestellung auf der Kassenseite eingeblendet werden.
- **Anzeige im Abschluss und Admin**: Kommissionskommentare erscheinen auf der Bestellbestätigungsseite und in der Bestellübersicht im Shopware-Admin.
- **Staffelpreise bleiben erhalten**: Mengen aller Teil-Positionen desselben Artikels werden für die Staffelpreisberechnung addiert.

## Voraussetzungen

- Shopware Version: 6.6.0 oder höher (bis 6.7.x)
- PHP Version: 8.2 oder höher

## Schnellstart

1. Installieren Sie das Plugin über den Plugin Manager oder via Composer.
2. Aktivieren Sie das Plugin unter **Erweiterungen → Meine Erweiterungen**.
3. Konfigurieren Sie die Grundeinstellungen unter **Erweiterungen → Meine Erweiterungen → SplitCommission → Konfigurieren**.
4. Wählen Sie, ob das Plugin für alle Produkte oder nur für ausgewählte Produkte aktiv sein soll.
5. Aktivieren Sie optional das globale Kommentarfeld für die Bestellübersicht.
