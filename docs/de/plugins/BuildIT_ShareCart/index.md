# BuildIT Share Cart

> Teile deinen Warenkorb ganz einfach per Link, E-Mail, WhatsApp oder Facebook.

## Übersicht

BuildIT Share Cart ermöglicht es Ihren Kunden, den aktuellen Warenkorb mit Freunden, Familie oder Kollegen zu teilen. Ihre Kunden wählen einfach eine Teilmethode aus, fügen optional einen Titel und eine Nachricht hinzu und versenden den Warenkorb-Link. Der Empfänger sieht alle Produkte auf einer übersichtlichen Landingpage und kann sie mit einem Klick in den eigenen Warenkorb übernehmen.

Das Plugin eignet sich ideal für B2B-Szenarien (Einkaufslisten an Kollegen senden), Geschenkempfehlungen oder gemeinsame Einkäufe. Die automatische Bereinigung sorgt dafür, dass alte geteilte Warenkörbe nicht dauerhaft in Ihrer Datenbank verbleiben.

## Hauptfunktionen

- **Teilen per Link**: Kunden kopieren einen Warenkorb-Link in die Zwischenablage
- **Teilen per E-Mail**: Öffnet eine vorausgefüllte E-Mail mit Titel, Nachricht und Link
- **Teilen per WhatsApp**: Sendet den Warenkorb-Link direkt über WhatsApp (mobil und desktop)
- **Teilen per Facebook**: Teilt den Warenkorb über den Facebook-Dialog (erfordert Facebook App ID)
- **Landingpage für Empfänger**: Übersichtliche Produktdarstellung mit Mengen und Preisen
- **Alle Produkte übernehmen**: Empfänger kann alle geteilten Produkte mit einem Klick in den eigenen Warenkorb legen
- **Automatische Bereinigung**: Geplante Aufgabe löscht alte geteilte Warenkörbe automatisch
- **CLI-Commands**: Manuelle Bereinigung über die Kommandozeile

## Voraussetzungen

- Shopware Version: 6.6 oder 6.7
- PHP Version: 8.2 oder höher

## Schnellstart

1. Installieren Sie das Plugin über den Shopware Store oder per ZIP-Upload
2. Aktivieren Sie das Plugin unter **Erweiterungen -> Meine Erweiterungen**
3. Konfigurieren Sie die Teilmethoden unter **Erweiterungen -> Meine Erweiterungen -> BuildIT Share Cart -> Konfigurieren**
4. Aktivieren Sie mindestens eine Teilmethode (Link, E-Mail, WhatsApp oder Facebook)

Im Storefront erscheint nun im Warenkorb ein "Warenkorb teilen"-Button.
