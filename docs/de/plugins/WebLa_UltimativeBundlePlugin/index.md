# Ultimatives Bundle Plugin

> Erstellen Sie Produktbundles mit automatischen Rabatten, flexiblen Gruppenkonfigurationen und mobiloptimierter Darstellung.

## Übersicht

Das Ultimative Bundle Plugin ermöglicht es Ihnen, attraktive Produktbundles in Ihrem Shopware-Shop zu erstellen. Kunden können auf der Produktdetailseite vorkonfigurierte Bundle-Angebote sehen und mit einem Klick alle Bundle-Produkte in den Warenkorb legen - inklusive automatischer Rabattberechnung.

Das Plugin eignet sich ideal für Cross-Selling-Strategien, Aktionsbundles oder Komplettangebote. Durch die flexible Gruppenstruktur können Sie verschiedene Produktkategorien kombinieren und Ihren Kunden die Wahl zwischen mehreren Optionen pro Gruppe lassen. Optionale Gruppen und individuelle Mengenauswahl pro Gruppe sorgen für maximale Flexibilität.

## Hauptfunktionen

- **Produktbundles erstellen**: Kombinieren Sie beliebige Produkte zu attraktiven Bundle-Angeboten mit automatischen Rabatten
- **Flexible Produktgruppen**: Organisieren Sie Bundle-Produkte in Gruppen mit jeweils eigener Produktquelle (manuelle Auswahl, Produktstreams oder Kategorien)
- **Optionale Gruppen**: Ermöglichen Sie Kunden, einzelne Gruppen eines Bundles abzuwählen
- **Mengenauswahl pro Gruppe**: Kunden können die Menge pro Bundle-Gruppe individuell festlegen (mit konfigurierbarer Maximalmenge)
- **Automatische Bundle-Erstellung**: Bundles werden optional automatisch zusammengestellt, wenn passende Produkte im Warenkorb liegen
- **Flexible Rabattkonfiguration**: Prozentuale Rabatte mit verschiedenen Berechnungsmodi und Darstellungsoptionen
- **Mobiloptimierte Darstellung**: Separate, für Mobilgeräte optimierte Ansicht der Bundle-Auswahl
- **Produktverfügbarkeitsprüfung**: Nicht verfügbare Produkte können automatisch ausgeblendet werden
- **Bundle-Index**: Schnelle Darstellung durch vorberechneten Index für Bundle-Produkt-Zuordnungen

## Voraussetzungen

- Shopware Version: 6.6.0 oder höher (bis 6.8.0)
- PHP Version: 8.2 oder höher

## Schnellstart

1. Installieren Sie das Plugin über den Plugin Manager oder Composer
2. Aktivieren Sie das Plugin unter **Erweiterungen → Meine Erweiterungen**
3. Konfigurieren Sie die Grundeinstellungen unter **Erweiterungen → Meine Erweiterungen → Ultimatives Bundle Plugin → Konfigurieren**
4. Erstellen Sie Ihr erstes Bundle unter **Kataloge → Bundles → Bundle anlegen**
5. Weisen Sie dem Bundle Produkte oder Produktgruppen zu und legen Sie den Rabatt fest
